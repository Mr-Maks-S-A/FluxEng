# Net — сеть для детерминированной симуляции (lockstep)

Симуляция детерминирована, поэтому по сети ходит не состояние мира, а **ввод**: каждый пир шлёт свои команды на тик
`T + input_delay`, а тик `T` исполняется, когда команды всех пиров на него собраны. Склейка идёт в порядке номеров пиров —
одинаково у всех. Хеши подсистем сверяются, расхождение называется по тику и подсистеме.

Подключение: `#include <Net/Lockstep.hpp>`, цель `engine::Net` (входит в `engine::Simulation`). Зависит от `Math` и `Replay` (тип `Command`, `StateHashes`).

```cpp
Net::Lockstep net(transport, {.local = my_id, .peers = 2, .seed = world_seed, .config_hash = level_hash, .input_delay = 3});
net.set_blob_reference(SpellSim::blob_reference);   // команда SetProgram ждёт свою программу

// каждый кадр:
net.pump();                                         // принять пакеты, отправить/повторить свои
if (net.needs_input()) net.submit(my_commands);     // свои команды на тик tick() + input_delay
if (net.ready()) {                                  // команды ВСЕХ пиров на tick() есть
    sim.tick(net.advance());                        // одинаково у всех
    net.report_hashes(sim.hashes());                // сверка именованных хешей
}                                                   // не готово — кадр без шага; игра не падает и не «уходит вперёд»
if (auto d = net.desync()) report(d->tick, d->subsystems);   // «разошлись на тике 912: mana»
```

Правки редактора идут тем же путём: программа уходит блобом (`net.submit_blob(Runes::encode_program(p))` → хеш), а в команде
`SpellSim::set_program_command(slot, hash)` — только хеш (16 байт). Команда не исполнится, пока блоб не пришёл и не сошёлся с хешем.

## Что внутри

| Часть | Идея |
|---|---|
| `Wire` (`encode`/`decode`) | пакеты `Hello`, `Inputs`, `BlobChunk`, `BlobAck`, `HashReport` с версией и CRC-32C; `decode` — граница доверия: любая порча или обрезка — отказ с текстом, не падение. Пакет ≤ 1200 байт (один MTU) |
| `Transport` | единственное, что протокол просит у сети: `send(peer, bytes)` и `receive(out)`. UDP подключается тонкой обёрткой |
| `LoopbackNetwork` | «плохая сеть» в памяти по сиду: задержка, разброс (перестановка), потери, дубликаты, порча бита, обрыв на лету (`set_link`). Тесты и примеры воспроизводимы |
| `Lockstep` | задержка ввода, склейка по пирам, подтверждения, повторы, блобы по хешу, сверка хешей, `stats()` |

**Надёжность без отдельных запросов.** Пакет `Inputs` несёт *все* ещё не подтверждённые тики и подтверждение принятых: потеря лечится
следующим пакетом, дубликаты и перестановки безвредны. Блоб идёт кусками по 1000 байт с подтверждением и повторами (не больше
`max_blob_chunks_per_pump` кусков на пира за `pump` — большой блоб не заглушает ввод). Знакомство (`Hello`) сверяет число игроков, сид и
`config_hash` (уровень, версия правил): несовпадение — `failure()`, шаги не делаются.

**Свойства, проверенные тестами:** на тике N состояние одинаково при любом качестве сети (идеальная; задержка 3 + разброс 4 + потери 20 % +
дубли + порча — результат тот же); три пира; блоб 2,6 КиБ при потерях 25 %, команда ждёт его; обрыв связи — игра стоит и догоняет после
восстановления; недетерминированный пир обнаружен на первом тике расхождения с названием подсистемы; фаззинг разбора пакетов.

## Границы

- Пиры считаются **честными**: подмена ввода и «мёртвый» блоб останавливают игру (`stalled_pumps`), но не карают. Исключение пира, таймауты,
  переподключение с досылкой состояния — следующий слой (у состояния уже есть хеши по подсистемам, а у `Replay` — потоковый журнал).
- Хеш содержимого блоба — FNV-1a 64 бита: защита от случайных ошибок, не от злоумышленника.
- В `SpellSim` пока один персонаж: пиры управляют им совместно (пилот ходит и кастует, писарь пишет заклинания — пример `Sandbox/CoopScribe`).
  Несколько персонажей — следующий шаг: идентификатор игрока в команде.

Примеры: `01_two_peers` (минимальный цикл), `02_bad_network_and_desync` (плохая сеть, обнаружение расхождения). Тесты: `NetTests`;
бенчмарки: `NetBenchmarks` (кодирование/разбор пакетов, кадр протокола на 2/4/8 пиров, потери, доставка блоба).
