# Язык рунных схем (`.circle`)

Заклинание — **схема**, как у транзистора (презентация «Грамматика рунного круга»):

| Роль | Что | В языке |
|---|---|---|
| Питание | мана среды: её много, она питает эффект | `Condenser` тянет её из среды в поток |
| Затвор | личная мана: её мало, она открывает и направляет поток | `signal a ~> b` — сигнал открывает руну |
| Цепь | рунная схема: как преобразуется поток, куда идёт, когда срабатывает | `flow a -> b -> c` |

Усиление = мана среды / личная мана = `skill × tools × purity`. Среды нет — работа «от батарейки» 1:1: везде, но дорого.

## Грамматика

```
spell Имя ring=6 time=10        # кольцо: область (м) и длительность (такты); заканчивается концом файла
caster skill=8 tools=1.5 purity=0.9 personal=60
world  mana=300 [fire=.. earth=.. air=.. water=..] [relax=0.08 saturation=30] [reset=1]
       [touch_at=1 distance=8 target=1]          # что «видят» сенсоры

rune id = Класс [параметр | ключ=значение ...]   # круг на дуге
flow   a -> b -> c               # сплошная дуга: поток маны среды
signal s ~> a                    # пунктир: управляющий сигнал личной маны

def Имя power=6                  # вложенный круг: схема внутри схемы
  rune a = In  ...  rune b = Out  # порты входа и выхода
  rune h = Heat use=$power
end
call x = Имя power=0.7           # вызов; x используется в flow как обычная руна
```

Параметры рун — «точки на круге»: сила (`power`, `ratio`, `use`), радиус (`radius`), время (`after`, `ticks`). `#` — комментарий.

## Классы рун

| Класс | Значение | Параметры |
|---|---|---|
| **Источники** `Condenser` | стягивает ману среды в поток | `power` (за такт) |
| **Накопители** `Capacitor` | копит заряд, отдаёт ровно | `cap`, `rate` |
| **Усилители** `Amplifier` | двигает больше маны среды на единицу личной | `ratio` |
| **Преобразователи** `Convert` | меняет аспект потока | `to=fire\|earth\|air\|water`, `share` |
| **Эффекторы** `Matter` `Heat` `Impulse` `Shape` | выход в мир; остаток потока идёт дальше | `use` (доля потока), `radius` |
| **Сенсоры** `Touch` `Target` `Timer` `Distance` | сигнал | `after`, `lt` |
| **Логика** `And` `Or` `Not` `Delay` `Counter` | сигнал из сигналов | `ticks`, `count` |
| `In` `Out` `Pass` | порты вложенного круга и простое звено | |

У всех рун потока есть `limit` (по умолчанию 30 за такт): течёт больше — **перегрузка**, срыв и взрыв.

## Аспекты и окраска среды

Круг родства: огонь — земля — вода — воздух — огонь; противоположные: огонь/вода и земля/воздух.
Потери при смене аспекта: тот же — 2 %, соседний — 10 %, из/в нейтральный — 25 %, противоположный — 60 %.
Потери и непрофильные остатки возвращаются в среду **окрашенными**: повтор того же аспекта дешевле, противоположный мешает
(порядок кастов — тактика). Окраска выцветает в нейтральную (`relax`, шаг `--gap`); избыток аспекта (`saturation`)
меняет мир: огонь поджигает, вода конденсируется, земля кристаллизуется.

## Проверка схемы

Разбор не падает, а называет файл, строку и причину: неизвестный класс или аспект, разрыв дуги (в руну не течёт поток),
петля, поток по сигнальному каналу и наоборот, вызов неизвестного круга, нет источника или эффектора, больше 32 рун в кольце.

## Запуск

```sh
build/bin/RuneCircuit                                  # примеры из circles/
build/bin/RuneCircuit meteor.circle --casts 3 --trace  # по тактам
build/bin/RuneCircuit fireball.circle iceball.circle --casts 1
build/bin/RuneCircuit --check                          # самопроверка, последняя строка OK
```
