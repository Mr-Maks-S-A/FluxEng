# ManaField — мана как физическое поле

Скалярное поле на сетке ячеек 2 м. Заклинание забирает ману из ячеек (`draw`) — в поле остаётся «дыра», которая затягивается:
диффузия потоками между соседями (сумма сохраняется точно) и возврат к базовому уровню (единственный источник маны).

Подключение: `#include <ManaField/ManaField.hpp>`, цель `engine::ManaField`. Зависит от `Math`.

## Разреженное и безграничное

- Незагруженная ячейка равна базе: **новое поле не занимает памяти**, шаг пустого поля — 1,5 нс.
- Чанки 16³ ячеек (32 м = 2×2×2 чанка `Terrain`) создаются при `draw` / `inject`; шаг добавляет «гало» — соседей по граням;
  чанк освобождается, когда все ячейки вернулись к базе.
- Ключи чанков — int64: мир ограничен только `WorldPos`.
- Хеш не зависит от выделения «пустых» чанков (детерминизм повторов).

```cpp
ManaField::ManaGrid grid;                                        // везде база, ни одного чанка
Math::Mana got = grid.draw(mage_pos, Math::Fixed::from_int(3), Math::Mana::from_int(240));
grid.step();                                                     // 10 раз в секунду
Math::Mana here = grid.density(mage_pos);                        // для рендера: яркость = плотность / база
```

| Метод | Что делает |
|---|---|
| `draw(pos, radius, amount)` | забирает пропорционально плотности ячеек в шаре; ≤ amount; ячейка не уходит ниже нуля |
| `inject`, `density`, `at` | добавить, прочитать (в ячейке точки / по индексу) |
| `step` | диффузия потоками + возврат к базе |
| `excess_raw` | Σ (ячейка − база): сохраняется диффузией, в том числе через границы чанков |
| `hash`, `version` | контрольная сумма и счётчик изменений (рендер пересобирает туман по нему) |
| `Config` | `diffusion` (≤ 1/6), `relax`, `base` — время затягивания дыры настраивается здесь (по умолчанию ≈ 6,5 с до 90 %) |

Пример — `examples/01_hole_that_heals.cpp` (дыра, ASCII-срез, затягивание, освобождение чанков). Тесты: `ManaFieldTests`.
Бенчмарк: шаг с дырой радиуса 8 м на углу восьми чанков ≈ 0,6 мс (бюджет 1 мс).
