# Character — управляемый персонаж

Капсула из трёх сфер, которая ходит, прыгает и кастует. Компоненты ECS: `Position`, `Velocity`, `Collider`, `ManaPool` (личная
мана восстанавливается сама), `Grimoire` (три слота со ссылками на заклинания по имени), `Motor` (желаемое направление и прыжок).

Подключение: `#include <Character/Character.hpp>`, цель `engine::Character`. Зависит от `Math` и `ECSSystem` — **не от ландшафта**:
столкновения идут по интерфейсу `Math::SdfField`, поэтому тот же код работает на ландшафте, плоскости и планете.

```cpp
ECS::Entity hero = Character::spawn(world, feet, {.current = 10_mana, .max = 100_mana, .regen = 5_mana}, {});
world.get<Character::Motor>(hero)->wish = {1_fx, 0_fx, 0_fx};     // игра ставит желаемое направление командой Move
Character::step(world, surface);                                   // тик: гравитация, столкновения, мана; surface — любой SdfField
```

| Что | Как |
|---|---|
| Движение | на земле скорость задаёт ввод (5 м/с), в воздухе — частично; гравитация — `Math::gravity(pos)` |
| Прыжок | одноразовый запрос, ≈ 2,9 м (7,5 м/с) |
| Столкновение | выталкивание из породы вдоль градиента SDF; «прилипание» к земле до 15 см (не отрывается на спуске, не зависает) |
| Порядок | сущности обходятся по id (`entities_of`), а не по порядку в пуле: результат не зависит от истории удалений |
| `hash_characters` | вклад в хеш состояния симуляции |

Пример — `examples/01_walk_on_plane.cpp` (падение, ходьба, прыжок, мана над `PlaneSdf`, без мира). Тесты: `CharacterTests`
(плоскость и шар — мгновенные; ландшафт — ходьба через весь мир, яма и выход из неё).
