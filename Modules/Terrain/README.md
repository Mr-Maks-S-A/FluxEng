# Terrain — ландшафт из знакового поля расстояний

Мир хранится как SDF в чанках 32³ (ячейка 0,5 м): отсчёт — расстояние до поверхности (int16 Q8.8) и материал. Внутри породы
значения отрицательные. Поверхность строится marching tetrahedra: **вершины на общей грани соседних чанков совпадают бит в бит**, швов нет.

Подключение: `#include <Terrain/Mesher.hpp>`, цель `engine::Terrain`. Зависит от `Math`, `MemorySystem`.

## Форма мира — данные

```cpp
Terrain::SdfWorld hills(/*seed*/ 7);                                      // 8×4×8 чанков = 128×64×128 м, холмы из шума
Terrain::SdfWorld flat(Terrain::Layout{2, 1, 3}, std::make_unique<MySource>());   // свой размер и свой ChunkSource
```

`Layout` — число чанков по осям; `ChunkSource::generate(coord, chunk)` — откуда берутся отсчёты (шум с сидом, плоскость, файл).
В одном процессе — сколько угодно миров (измерения, планеты, тесты).

## Запросы и правки

| Метод | Что делает |
|---|---|
| `sample(pos)`, `gradient(pos)` | расстояние (м, трилинейно) и нормаль; `SdfWorld` — это `Math::SdfField`; за краем мира — порода, сверху — воздух |
| `raycast(origin, dir, max)` | луч по длине шага из расстояния |
| `ground_height(column)` | высота земли над колонкой |
| `carve_sphere`, `add_sphere` | `d = max(d, −s)` / `d = min(d, s)`; возвращают `EditResult` (границы и затронутые чанки, включая соседей, читающих край) |
| `take_dirty()` | очередь чанков, чьи сетки нужно перестроить (без повторов) |
| `load_chunk(coord, data)`, `modified(coord)` | подмена данных чанка целиком (загрузка снимка); менялся ли чанк с генерации — нужные снимку чанки |
| `hash()` | хеш всех отсчётов (пересчитываются только изменённые чанки) |
| `mesh_chunk(world, coord[, out])` | сетка поверхности чанка: позиции от угла чанка, нормали из градиента; читает мир константно — можно из многих потоков |
| `distance_at` / `raw_distance_at` | расстояние отсчёта в метрах / сырой формат хранения (Q8.8) для мешера и сериализации |

Всё в Fixed и целых; float только в сетке (`ChunkMesh`) — это отображение.

Примеры: `01_dig_and_raycast.cpp` (запросы, луч, правка, очередь, хеш), `02_custom_world.cpp` (форма и источник мира).
Тесты: `TerrainTests` (швы, детерминизм, формы мира); бенчмарк: чанк ≈ 0,8 мс (бюджет 2 мс).
Отложено: Transvoxel и LOD (таблицы ячеек совместимы, лицензия проверяется при подключении).
